# Cognifyz Technologies – Web Development Internship

## Internship Overview

This repository contains the projects and assignments completed as part of the Web Development Internship at **Cognifyz Technologies**.

The internship focused on developing practical frontend development skills through HTML, CSS, JavaScript and responsive web design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Responsive Web Design
- Visual Studio Code
- Git and GitHub

## Project Structure and Tasks

### Level 1 – Web Development Fundamentals

**Task 1: Personal Webpage**
- Created a webpage using HTML and CSS.
- Implemented headings, paragraphs and images.
- Applied styling and layout properties.

**Task 2: JavaScript Fundamentals**
- Developed a button that changes colour when clicked.
- Implemented a time-based greeting alert.
- Built a calculator to add two numbers.

### Level 2 – Frameworks and Responsive Design

**Task 1: Frontend Frameworks**
- Created responsive cards using Bootstrap.
- Implemented a responsive grid layout.
- Used Bootstrap's grid system and components.

**Task 2: Responsive Web Design**
- Developed a responsive developer portfolio webpage.
- Implemented CSS media queries.
- Created a mobile-friendly hamburger navigation menu using JavaScript.

### Level 3 – Advanced Frontend Development

**Task 1: Image Manipulation**
- Developed an interactive image gallery.
- Implemented enlarged image previews.
- Created an automatic slideshow.
- Added previous, next, play and pause controls.

**Task 2: Internship Landing Page**
- Designed a Web Developer Internship landing page for Cognifyz Technologies.
- Added an introduction, program highlights and qualifications.
- Implemented call-to-action buttons.
- Included contact information and responsive navigation.

## Key Learning Outcomes

- Understanding semantic HTML and webpage structure.
- Applying CSS styling, layouts and responsive techniques.
- Implementing JavaScript DOM manipulation and event handling.
- Building responsive interfaces using Bootstrap.
- Developing interactive web components.
- Organizing and maintaining frontend projects.
